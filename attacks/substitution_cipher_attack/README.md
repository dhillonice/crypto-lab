# Assignment 5: Monoalphabetic Substitution Cipher and Cryptanalysis

## Aim

To implement a monoalphabetic substitution cipher and perform cryptanalysis using frequency analysis, word frequency analysis, and pattern analysis.

## Objectives

- Implement monoalphabetic substitution cipher encryption.
- Generate ciphertext from plaintext.
- Perform frequency analysis.
- Analyze word frequencies and word lengths.
- Identify repeated word and letter patterns.
- Recover the substitution key.
- Recover the plaintext.
- Verify the recovered key by re-encrypting the plaintext.
