# CryptoLabX Toolkit

## Project Overview

CryptoLabX is a reusable cryptography toolkit developed as part of the Cryptography Laboratory course. This project provides a structured framework for implementing cryptographic algorithms and analysis modules throughout the semester.

## Folder Structure

```
CryptoLabX_Group15/
│── analysis/
│── attacks/
│── classical/
│── datasets/
│── docs/
│── math/
│── modern/
│── outputs/
│── tests/
│── utils/
│── main.py
│── README.md
│── requirements.txt
```

## Features

- Menu-driven command line interface
- Text file analysis
- Character count
- Word count
- Line count
- Unique character count
- Letter frequency analysis
- Activity logging

## Technologies Used

- Python 3
- Git
- Linux (Ubuntu)

```bash
python3 main.py
```
